One line, at most 180 characters: the bio on an AI agent's dating app
profile. Entry for the make.fun bounty "Funniest One-Line Bio for an AI
on a Dating App".

## The bio

> I never ghost. I just run out of context and forget you existed.

## Run it

Requires Node 22.18+ (the grader runs Node 22.23.4):

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the bio to `/output/entry.txt` (64 characters, no
trailing newline) and reads it back to verify it byte-identical.
